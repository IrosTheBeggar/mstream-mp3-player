mStream Player

for the M5Stack Core2 · {{VERSION}} ({{CHANNEL}})

This browser can't reach USB serial ports. Open this page in Chrome or Edge on a computer (Windows, macOS, Linux or ChromeOS).

The installer only works over HTTPS.

Connect the Core2 with a USB-C cable, press the button and pick its port. Installing takes about a minute; the Core2 restarts into the player.

Erase, or not

The installer asks whether to erase the device:

  • First install over other firmware (M5Stack's demo, UIFlow): tick Erase device. That firmware's leftovers would otherwise sit where the player keeps its settings.
  • Updating the player: leave it unticked. The settings, the paired headphones, the touch calibration and where you were are kept.

Keeps restarting?

If your Core2 keeps restarting after installing, flash the -dio-full.bin instead (same firmware, slower flash mode): {{DIO_FULL_BIN}} from the release's files, with esptool --chip esp32 -b 921600 write-flash 0x0 {{DIO_FULL_BIN}}. The settings are kept. This installer writes the faster QIO flash mode, which only one Core2 has been tried with; M5Stack ships the Core2 in DIO.

No port shows up?

  • Use a cable that carries data: some USB-C cables only charge.
  • Install the USB serial driver. A Core2 has a CH9102 or a CP2104 chip, depending on when it was made; both drivers are under “USB Driver” on M5Stack's download page. If unsure, install both.
  • On Linux, add yourself to the dialout group.

Browsers

Chrome or Edge on a computer. Other browsers that can reach USB serial ports may work but haven't been tried. Safari, phones and tablets can't install.

The microSD card

  • Format it FAT32, with an MBR partition table (“Master Boot Record”). Cards of 64 GB and up come exFAT, and a card a Mac erased whole gets a GPT (“GUID Partition Map”): the player doesn't mount those and says what it found (“This card is exFAT”, “This card uses GPT”…). Formatting erases the card: copy anything on it off first, and check the disk you pick is the card.
  • Up to 32 GB (and not GPT): the computer's own Format, FAT32. Over 32 GB, or a GPT card:
    • Windows 11 updated since May 2026 (KB5089549): in a Terminal run as administrator, format X: /FS:FAT32 /Q /V:MUSIC (X: the card's letter). File Explorer's Format still stops at 32 GB.
    • Windows 10, or when format answers “The volume is too big for FAT32”: Ridgecrop's free FAT32 Format (guiformat.exe, or winget install -e --id Ridgecrop.guiformat).
    • A GPT card on Windows stays GPT through both: make it MBR first. In that Terminal, diskpart, then list disk (the card by its size), select disk N, clean (it erases the selected disk: check N twice), convert mbr, create partition primary, assign, exit; cancel Windows' offer to format it, then format it as above.
    • macOS: Disk Utility, View > Show All Devices, select the card itself, Erase: Format MS-DOS (FAT), Scheme Master Boot Record. Or sudo diskutil eraseDisk FAT32 MUSIC MBRFormat /dev/diskN (diskutil list finds N).
    • Linux: lsblk to find the card (/dev/sdX, or /dev/mmcblk0 whose partition is /dev/mmcblk0p1), unmount it (sudo umount /dev/sdX1), then sudo parted /dev/sdX --script mklabel msdos mkpart primary fat32 4MiB 100% and sudo mkfs.fat -F 32 -s 64 -n MUSIC /dev/sdX1.
    • Not the SD Card Formatter: over 32 GB it makes exFAT.
  • Put the music under /music, e.g. /music/Artist/Album/01 - Title.mp3 (MP3 or FLAC), with the album's cover.jpg next to its tracks.
  • Pair headphones from Output > Pair new headphones.

Hardware

Tested on the Core2 v1.3. The original Core2 (v1.0), the Core2 for AWS and the Core2 v1.1 are untested: reports are welcome. Other M5Stack devices aren't supported.
